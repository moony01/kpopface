# Canvas API 결과 이미지 생성 기능

> K-Pop Face Test 결과를 공유용 이미지로 생성하는 기능 명세

## 1. 개요

### 목적
사용자가 테스트 결과를 **이미지로 저장/공유**하여 바이럴 마케팅 효과 극대화

### 왜 Canvas API인가?

| 방법 | 장점 | 단점 | 비용 |
|------|------|------|------|
| **Canvas API** | 서버 불필요, 즉시 생성 | 초기 개발 필요 | **0원** |
| html2canvas | 구현 쉬움 | 품질 낮음, 폰트 깨짐 | 0원 |
| 서버 생성 (Puppeteer) | 품질 최상 | 서버 비용, 속도 느림 | Lambda 과금 |
| Canva API | 템플릿 이쁨 | API 비용 | 월 $30+ |

**결론**: Zero-Cost 철학에 Canvas API가 최적

## 4. 구현 코드

### 4.1 이미지 생성 함수 (static/js/imageGenerator.js)

```javascript
/**
 * Canvas API로 K-Pop Face Test 결과 이미지 생성
 * 
 * @param {Object} data - 결과 데이터
 * @param {string} data.agency - 소속사 코드 (sm, jyp, yg)
 * @param {string} data.title - 결과 제목 (예: "SM얼굴상")
 * @param {string} data.explain - 해시태그 설명
 * @param {string} data.celeb - 대표 연예인
 * @param {string} data.lang - 언어 코드
 * @returns {Promise<Blob>} PNG 이미지 Blob
 */
async function generateResultImage(data) {
  const { agency, title, explain, celeb, lang } = data;
  
  // 폰트 로드 대기
  if (document.fonts) {
    await document.fonts.ready;
  }

  // 1. Canvas 생성 (인스타 스토리 비율)
  const canvas = document.createElement('canvas');
  canvas.width = 1080;
  canvas.height = 1920;
  const ctx = canvas.getContext('2d');

  // 2. 소속사별 배경 그라데이션
  const colors = getAgencyColors(agency);
  const gradient = ctx.createLinearGradient(0, 0, 0, 1920);
  gradient.addColorStop(0, colors.main);
  gradient.addColorStop(1, colors.sub);
  ctx.fillStyle = gradient;
  ctx.fillRect(0, 0, 1080, 1920);

  // 3. 상단 로고
  ctx.fillStyle = '#FFFFFF';
  ctx.font = 'bold 55px Pretendard, sans-serif';
  ctx.textAlign = 'center';
  ctx.fillText('K-POP Face Test', 540, 180);

  // 4. 소속사 로고/아이콘
  try {
    const icon = await loadImage(`/kpopface/static/img/agency/${agency}.png`);
    ctx.drawImage(icon, 390, 400, 300, 300);
  } catch (e) {
    // 아이콘 없으면 이모지 대체
    ctx.font = '180px sans-serif';
    ctx.fillText(getAgencyEmoji(agency), 540, 600);
  }

  // 5. 결과 텍스트
  ctx.font = 'bold 90px Pretendard, sans-serif';
  ctx.fillStyle = '#FFFFFF';
  ctx.fillText(title, 540, 850);

  // 6. 해시태그
  ctx.font = '42px Pretendard, sans-serif';
  ctx.fillStyle = '#F0F0F0';
  wrapText(ctx, explain, 540, 960, 900, 55);

  // 7. 대표 연예인 (축약)
  ctx.font = '36px Pretendard, sans-serif';
  ctx.fillStyle = '#E0E0E0';
  const shortCeleb = celeb.length > 60 ? celeb.substring(0, 60) + '...' : celeb;
  wrapText(ctx, shortCeleb, 540, 1200, 900, 50);

  // 8. 하단 CTA
  ctx.font = 'bold 50px Pretendard, sans-serif';
  ctx.fillStyle = '#FFED4E';
  const ctaText = lang === 'ko' ? '나도 테스트 하기!' : 'Try the test!';
  ctx.fillText(ctaText, 540, 1650);

  // 9. URL 워터마크
  ctx.font = '40px Pretendard, sans-serif';
  ctx.fillStyle = '#FFFFFF';
  ctx.fillText('moony01.com/kpopface', 540, 1750);

  // 10. PNG Blob 반환
  return new Promise((resolve) => {
    canvas.toBlob(resolve, 'image/png', 1.0);
  });
}

// 소속사별 색상 반환
function getAgencyColors(agency) {
  const colorMap = {
    sm: { main: '#0066FF', sub: '#00D4FF' },
    jyp: { main: '#00C853', sub: '#69F0AE' },
    yg: { main: '#212121', sub: '#616161' }
  };
  return colorMap[agency] || colorMap.sm;
}

// 소속사별 대체 이모지
function getAgencyEmoji(agency) {
  const emojiMap = { sm: '💙', jyp: '💚', yg: '🖤' };
  return emojiMap[agency] || '🎤';
}

// 이미지 로드 헬퍼
function loadImage(url) {
  return new Promise((resolve, reject) => {
    const img = new Image();
    img.crossOrigin = 'anonymous';
    img.onload = () => resolve(img);
    img.onerror = reject;
    img.src = url;
  });
}

// 텍스트 자동 줄바꿈
function wrapText(ctx, text, x, y, maxWidth, lineHeight) {
  const words = text.split(' ');
  let line = '';
  let currentY = y;

  words.forEach((word) => {
    const testLine = line + word + ' ';
    const metrics = ctx.measureText(testLine);
    if (metrics.width > maxWidth && line !== '') {
      ctx.fillText(line.trim(), x, currentY);
      line = word + ' ';
      currentY += lineHeight;
    } else {
      line = testLine;
    }
  });
  ctx.fillText(line.trim(), x, currentY);
}
```

### 4.2 공유/다운로드 함수 (static/js/app.js에 추가)

```javascript
// 결과 이미지 저장/공유
async function fnSaveResultImage() {
  const saveBtn = document.getElementById('save-image-btn');
  if (saveBtn) saveBtn.disabled = true;

  try {
    // 현재 결과 데이터 수집
    const data = {
      agency: currentAgency,      // predict()에서 설정한 전역 변수
      title: currentResultTitle,
      explain: currentResultExplain,
      celeb: currentResultCeleb,
      lang: langType || 'ko'
    };

    // Canvas로 이미지 생성
    const imageBlob = await generateResultImage(data);
    const imageFile = new File([imageBlob], 'kpop-face-result.png', { type: 'image/png' });

    // 모바일: Web Share API
    if (navigator.canShare && navigator.canShare({ files: [imageFile] })) {
      await navigator.share({
        files: [imageFile],
        title: 'K-POP Face Test Result',
        text: data.title
      });
    } else {
      // PC: 자동 다운로드
      const url = URL.createObjectURL(imageBlob);
      const a = document.createElement('a');
      a.href = url;
      a.download = 'kpop-face-result.png';
      document.body.appendChild(a);
      a.click();
      document.body.removeChild(a);
      URL.revokeObjectURL(url);
    }
  } catch (error) {
    console.error('이미지 생성 실패:', error);
    alert('이미지 생성에 실패했습니다. 다시 시도해주세요.');
  } finally {
    if (saveBtn) saveBtn.disabled = false;
  }
}
```

## 5. Canvas API 핵심 메서드 참고

| 메서드 | 역할 | 사용처 |
|--------|------|--------|
| `fillRect(x, y, w, h)` | 사각형 채우기 | 배경 |
| `fillText(text, x, y)` | 텍스트 쓰기 | 제목, 설명 |
| `drawImage(img, x, y, w, h)` | 이미지 그리기 | 소속사 아이콘 |
| `createLinearGradient()` | 그라데이션 | 배경 효과 |
| `canvas.toBlob()` | PNG 변환 | 다운로드/공유 |
